# 🌍 ROMA Multilingual Music App

A sophisticated, modern multilingual audio platform designed to bridge cultures through music. 

---

## 🌟 Overview
**ROMA** is an interactive web application built with React and Tailwind CSS, featuring a dynamic interface that supports seamless switching between multiple languages and writing systems (including dynamic LTR/RTL text display). It offers a culturally rich music experience with customized palettes for diverse musical genres.

---

## ✨ Key Features
* **Multilingual & Multi-script Support:** Seamless UI adaptation for different languages with dynamic layout orientation (LTR/RTL).
* **Sunset Gradient Theme:** A stunning, culturally inspired aesthetic utilizing modern CSS styling and color transitions.
* **Featured Collections:** Curated musical categories representing different global traditions (Oud Nights, Bollywood Pulse, New Eastern Rhyme).
* **Interactive Mini Player:** Smooth playback controls and responsive navigation.

---

## 🛠️ Tech Stack
* **Frontend:** React, Vite
* **Styling:** Tailwind CSS
* **Icons:** Lucide React
